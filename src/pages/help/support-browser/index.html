サポートブラウザ

YDITS for Web では、以下のブラウザをサポートしています。

  • Chromium ベース - Blink系 (V8) 準拠

    • Google Chrome (最新バージョン)
    • Microsoft Edge (最新バージョン)
    • Vivaldi (最新バージョン)
    • Opera (最新バージョン)

  • Firefox ベース - Gecko系 (SpiderMonkey) 準拠

    • Mozilla Firefox (最新バージョン)
    • Floorp (最新バージョン)

以下のブラウザは、一部の機能が正しく動作しない可能性があります。

  • WebKit系 (JavaScriptCore)

    • Apple Safari

      • プッシュ通知が利用できない可能性があります。
      • Service Worker が利用できない可能性があります。
